# 点検カード

Excel の点検表を読み込み、項目ごとのカードで入力して、空いている列に書き戻す PWA。
外部ライブラリなし・ビルド不要。一度開けば Wi-Fi なしで動く。

## 構成

| パス | 内容 |
|---|---|
| `app/` | 配布するアプリ本体 (このフォルダだけを HTTPS で公開すればよい) |
| `app/zip.js` | ZIP 読み書き。未変更エントリは圧縮データをそのままコピー |
| `app/xlsx.js` | シート解析・レイアウト推定・セル XML の差し替え |
| `app/profile.js` | 設定ファイル (点検表ごとの JSON) に従ってカードを組み立てる |
| `app/app.js` | 画面 (ホーム / 列選択 / カード入力 / 書き出し) |
| `app/store.js` | IndexedDB への自動保存 |
| `app/sw.js` | オフライン用キャッシュ。**アプリ更新時は `VERSION` を上げる** |
| `dev/` | 開発用 (サーバー、検証スクリプト、ダミー点検表) |

## 設定ファイル (点検表ごとの専用設定)

**点検表に固有の名前・行・見出しは、このリポジトリには一切書かない** (公開リポジトリのため)。
それらは設定ファイル (JSON) に書き、点検表と同じ非公開の場所に置く。iPad ではホーム画面の
「設定ファイルを読み込む」で一度取り込めば端末内に保存される。

設定ファイルで指定できること (`app/profile.js` の `buildProfileCards` を参照):

- `fileMatch`: 対象ファイル名に含まれる文字列。点検表を開いたときは、これでその点検表用の設定を選ぶ
- `sheet` / `headerCheck`: 対象シート名と、列の見出しセルの期待値。シートは名前ではなく **列の見出しがすべて合うシート** から選ぶ
  (シート名は改訂で変わることがあるため)。合うシートが複数あると選ぶまで始められず、選んだシートは端末に記憶する
  (候補の組み合わせが変わったら選び直し)。合うシートがないときは、表が改訂されたとみなして Excel での入力を案内する
- `meta`: 基本情報 (日付・時間・担当) のラベル列とラベル
- `records.startCol`: 記録列の開始列。書き込み先は最後に記録がある列の右隣
- `items`: 項目の開始行、行を特定するキー列、項目の終わりを示す目印。
  行の指定 (`{"no", "name", "_row"}`) は、キー列の値 `no` と項目名 `name` で行を探す。同じキーの行が複数あるときは項目名が合う行、
  それでも複数なら控えの行番号 `_row` の行を使う。キー列が空の行は `"no": ""` と項目名で指定する
- `columns`: 区分・項目名・補足・単位・読取場所・設定値・最小・判定種別・最大・影響・備考 (`note`)・桁数 の列。
  備考の列と、項目の列に付いたセルのコメントはカードに「備考」として表示する。過去の記録に付いたコメントは、いちばん新しいものを「前回メモ / メモ (日付)」として表示する
- `defaultType`: 単位・設定値・範囲・前回値のどれからも種類が分からない行の入力方法 (`"number"` で数値入力)
- `rowTypes`: 行ごとの入力方法の指定 (自動判定より優先)。`options` で選択式 (`"A|B|C"` または配列)、
  または `type` に `"number"` / `"text"`。例: `{"no": "10", "name": "項目名", "options": "A|B|A/B"}`。
  `disabled` に書いた選択肢は表示するが押せない (例: `"options": "A|B", "disabled": "A"`)
- `kinds`: 判定種別の文字 (`range` 管理幅 / `reference` 参考)。`tolerance` に `"設定±"` のように書くと、「設定±2」は設定値±2 を管理幅にする、`choiceSets`: 選択肢のセット (例: ON/OFF)
- `conditions`: 条件による行の振り分け
  - `source` + `match.token`: ある項目の入力値と同じ単語を含む行だけを対象にする
  - `source` + `match.band`: 数値の帯 (例: 「AB10～20」) に入る行だけを対象にする
  - `rows` (+ `placeBefore`, `writes`): 選択式。選んだ側の行だけを対象にし、指定セルに選択値を書く
- `exclude`: 対象外の行
- `optionalRows`: 任意入力の行。空欄でも進み具合・未入力の数に含めない (入力すれば書き込み・判定する)
- `splitGroups`: 列分け表示。指定した行を列 (`by`、既定は補足列) の値ごとに分けて一覧表示し、幅があれば横に並べる。
  `pattern` (正規表現) を書くと項目名から値を取り出す (例: `"(OS|DS)\\s*$"`。取り出した部分は項目名の表示から省く)。
  入力の順番は `order` の順に、値ごとに上から下へ
- `formulaRows`: 自動計算の行。今回の列に式を書き込み、値は入力から計算して表示・判定する (入力は不要)。
  式は `formula` (`{col}` が今回の列、例: `"{col}118-{col}116"`) か、省略すると前回までの記録で最後に式が入っている列からずらして作る。
  使える式: 四則演算・括弧・セル範囲・MAX MIN SUM AVERAGE ABS ROUND
- `sectionRows`: 見出し (区分) の指定。区分の列の値の代わりに `section` の見出しにまとめる。例: `{"section": "見出し", "rows": [{"no": "10", "name": "項目名"}]}`
- `compactRows`: 一覧表示 (項目名と入力欄を 1 行にして縦に並べる) にする行。紙の点検表と見比べる項目向け

行は「キー列の値 + 項目名」で指定し、読み込み時に項目名が合わなければ警告してその振り分けを使わない。

## 設定ファイルがない場合の自動判定 (簡易)

- ラベル列に「日付」があり、その右の列が 1 回分の記録 (横に追記していく)
- 「日付」より上〜ヘッダ行までのラベル列 = 基本情報 (日付・時間・名前…)
- ヘッダ行 (機器名称/記号/管理値/連絡先…) より下で、左側に項目名がある行 = 点検項目
- 書き込み先の既定は「最後に記録がある列の右隣」。既存の列を選ぶと、その列の空欄だけに書き込む
- 値・数式が入っているセルは上書きしない。書式は前回の列の同じ行からコピーする

## 開発 (Windows)

```
py dev/serve.py 8765
```

`http://localhost:8765/app/` を開く。`POST /dev/save?name=x.xlsx` で `dev/out/` に保存できる (自動テスト用)。
非公開の点検表で試すときは、リポジトリのフォルダにコピーせず `--ext <フォルダ>` (`/ext/` で読み取り専用配信) と
`--out <フォルダ>` (書き出し結果の保存先をリポジトリ外にする) を使う。
出力の検証: `python dev/verify.py <元.xlsx> <出力.xlsx> <列名> [シート名] [前回の列名]` (openpyxl が必要)

## iPad での使い方

Service Worker は HTTPS でないと動かないため、`app/` を GitHub Pages で公開している。
`main` に push すると `.github/workflows/pages.yml` が `app/` だけを公開する (xlsx は `.gitignore` で除外)。
**アプリを更新したら `app/sw.js` の `VERSION` を上げてから push する** (上げないと iPad に古い版が残る)。
アプリは開いたとき・ホーム画面から戻ったときに (オンラインなら) 新しい版を確認し、ホーム下部に「アプリの版」を表示する。
新しい版を読み込むと「再読み込み」の案内が出る。

1. Wi-Fi がある場所で Safari から URL を開き、共有 → 「ホーム画面に追加」
2. ホーム画面のアイコンから起動 → 「点検表を開く」で「ファイル」アプリの xlsx を選ぶ
3. 以降はオフラインで入力可。入力内容は 1 項目ごとに端末内へ自動保存される
   数値の項目では画面下にアプリのテンキーが出る (iPad の画面キーボードはテンキーにならないため)。「Enter」で次の項目へ (空欄なら前回値で確定)、「BS」で 1 文字消す。左側の「▲ 戻る」「▼ 進む」で値はそのまま前後の項目へ移る。入力済みの欄は打ち直すと置き換わる
   テンキーの上端のつまみで高さ、テンキー部分の左端のつまみで横幅を変えられる (端末・縦横ごとに記憶。つまみのダブルタップで元に戻す)
   ヘッダーの「A」で文字サイズを 標準 → 大 → 特大 → 小 と切り替えられる (端末に記憶)
   iPhone など狭い画面では、入力できる範囲を広げるため絞り込みの行と区分の見出しを省き、テンキーの戻る・進む・閉じるは ▲ ▼ × だけにする
4. 「書き出し」→「共有 / ファイルに保存」で、書き込み済みのファイルを「ファイル」に保存。名前は元と同じ。同じ名前があると、保存先によって
   「置き換え」を聞かれるか、末尾に「 2」「 3」などの番号が付く (番号が付いたら、続きは番号のいちばん大きいファイルを開く。古いものは適宜消す)
   置き換えた後に元へ戻したいときは、ホームの「作業中の点検表」の「元のファイル」で読み込み時点のファイルを保存し直せる (作業を削除するまで)
